# DEALFLOW — Roadmap

## Now (v0.1.x)
- Stable `scan` CLI (table / JSON), CI fail-gate, MCP server, demo scenarios.

## Now (v0.7)
- Capital-matchmaking + strategic-teaming engine: `match` (explainable fit
  scoring), `sources` (funding-vehicle taxonomy), `team` (teaming graph + gap
  analysis), `pipeline` (capture tracker), `report` (self-contained HTML/CSV/JSON).

## Next (v0.8)
- Expand the rule/heuristic set and connectors.
- Community-contributed capital-source catalog entries and teaming rosters.
- Niche focus: Pipeline-as-code: your forecast is a reproducible artifact in CI, so board decks come from a committed file instead of a manually massaged spreadsheet..

## Later (v1.0)
- PyPI release, plugin API, Pro tier + commercial support (licensing@cognis.digital).
